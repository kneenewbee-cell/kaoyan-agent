# 数三 1987-2005 入库设计

**目标**

将 `1987-2005` 年考研数学三真题与答案解析，按当前 `math2` 已验证的正式格式，落入 `data/raw/math/exam_papers/math3/<year>/`，生成可重建、可抽查、可检索的年度产物与单题卡片。

**范围**

- 年份范围：`1987-2005`
- 科目范围：`数学三`
- 源文件位置：
  - 真题：`D:\百度网盘\高数资料\【01】1987-2022考研数学三真题（PDF）`
  - 答案：`D:\百度网盘\高数资料\【02】1987-2022考研数学三答案解析（PDF）`

**输入组织**

- `1987-1996` 使用真题合集 `【合集打印】1987-1996考研数学三真题【43页】.pdf`
- `1997-2005` 使用真题合集 `【合集打印】1997-2009考研数学三真题【40页】.pdf`
- 答案解析使用逐年 PDF

**输出格式**

严格对齐当前 `math1` 正式目录与文件格式。每年输出到 `data/raw/math/exam_papers/math3/<year>/`，包含：

- `math3_<year>_questions.md`
- `math3_<year>_answers.md`
- `questions.jsonl`
- `paper_manifest.json`
- `questions/q001.md` 到当年最后一题
- `images/source_pages/`
- `images/answer_pages/`
- 年度构建脚本与原始结构化题库文件

对齐要求包括：

- 年目录命名方式
- 年度 `questions.md / answers.md / questions.jsonl / paper_manifest.json` 的字段结构
- 单题 `qXXX.md` 的 front matter 字段、章节顺序与来源字段
- 题型标签、模块字段、题号编号规则
- 图像引用路径组织方式

**数据约束**

- 题目、答案、解析同时保留
- 单题卡片与年度汇总内容一致
- 能文本化的题尽量文本化
- 图形题保留必要图像，不带页边干扰信息
- 解析允许基于答案页与题面做“简洁但正确”的补全，不伪造原 PDF 不存在的长篇文字

**执行策略**

- 按年份块执行，先 `1987-1996`，后 `1997-2005`
- 同一时间只让不同子任务处理不同年份或年份块，避免目录冲突
- 延续 `math2/2021-2024` 的构建模式：优先使用结构化源数据 + 构建脚本重建正式产物

**校验标准**

每年完成后必须校验：

- `questions/` 题卡数量正确
- `questions.jsonl` 行数与题卡数一致
- `paper_manifest.json` 中 `question_count`、`explanation_count` 正确
- 年度构建脚本可重新运行
- `git diff --check -- data/raw/math/exam_papers/math3/<year>` 通过

**风险点**

- 早年真题与答案页版式差异较大，题号映射要逐题确认
- `1987-1989` 可能带“试卷四”字样，需要按当前库实际年份目录规范落地，不保留旧卷别名作为主标识
- 图形题与长公式题容易出现 OCR/转写误差，需要优先依赖页图人工校对

**完成定义**

当 `1987-2005` 每个年份目录均具备正式产物、构建脚本可重跑、数量校验通过后，视为本阶段完成。
