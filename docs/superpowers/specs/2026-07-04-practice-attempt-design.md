# 练习单作答与提交记录设计

日期：2026-07-04
阶段：产品设计确认稿
适用范围：系统资料库中的练习单、复习规划入口

## 1. 目标

把当前“练习单详情页”升级为可作答、可提交、可核对、可沉淀记录的练习体验。第一版目标不是完整考试系统，而是补齐练习单从“题目集合”到“用户练习记录”的闭环，为后续左侧复习规划页中的 AI 规划提供可靠数据。

核心目标：

- 用户可以打开练习单并开始一次练习。
- 用户可以填写选择题、填空题、解答题答案。
- 用户提交后生成一次不可修改的练习记录。
- 系统可以自动核对选择题和部分填空题。
- 解答题先显示标准答案与解析，可选择让 AI 做参考评分。
- 练习结果可以影响错题、掌握状态、复习规划建议。

## 2. 明确边界

第一版采用“考试记录型”：

- 一次提交生成一个 `practice_attempt`。
- 提交后本次记录不可修改。
- “再次练习”第一版只保留占位入口，不实现完整重练流程。
- 如果后续实现再次练习，应创建新的 `practice_attempt`，不覆盖旧记录。

暂不做：

- OCR 识别手写过程。
- 复杂数学等价判分。
- AI 自动接管所有题型判分。
- 大型考试计时、排名、错题智能出卷。

## 3. 推荐页面方案

采用“整卷练习 + 右侧答题卡”。

页面结构：

- 主区域展示整张练习单，连续阅读题目。
- 右侧答题卡展示题号、作答状态、用时、提交入口。
- 单题保留“查看详情 / 解析 / 加入错题 / 标记掌握”等操作，但不把练习流程塞进详情抽屉。

选择这个方案的原因：

- 练习单看起来像一张卷子，符合用户对“做题”的心理模型。
- 右侧答题卡能快速跳转题目、发现未答题。
- 后续加入提交记录、结果页、AI 评分更自然。
- 比逐题模式更适合数学真题和同类训练。

## 4. 用户流程

### 4.1 开始练习

入口：

- 练习单详情页的“开始练习”按钮。
- 复习规划页中练习单任务的“开始复习”按钮。

动作：

- 创建或恢复一个未提交的草稿 attempt。
- 进入整卷练习页。
- 右侧答题卡显示未答、已答、当前题。

完成态：

- 页面显示“练习中”。
- 草稿自动保存。

反向操作：

- “暂存退出”：保存草稿并返回来源页。
- “放弃本次”：删除未提交草稿或标记为 abandoned。

### 4.2 作答

选择题：

- 显示 A/B/C/D 选项按钮。
- 用户点击后写入草稿答案。

填空题：

- 显示输入框。
- 第一版只保存用户输入，不做复杂公式编辑器。

解答题：

- 显示多行文本框。
- 用户输入主要步骤。
- 第一版不做 OCR；用户可以手动复述关键步骤。

### 4.3 提交确认

入口：

- 右侧答题卡中的“提交练习”。

确认信息：

- 已答题数。
- 未答题数。
- 解答题是否为空。
- 提醒“提交后本次记录不可修改”。

动作：

- 用户确认后锁定 attempt。
- 写入提交时间、用时、每题答案。
- 触发自动核对。

反向操作：

- “返回继续作答”：关闭确认弹窗，保持草稿。

### 4.4 结果核对

提交后进入结果页。

结果页显示：

- 总览：正确题数、错误题数、待核对题数、待评分题数。
- 每题行：题号、你的答案、标准答案、结果、后续动作。
- 题型分组：选择题、填空题、解答题。

选择题：

- 自动核对标准答案。
- 结果为 correct / incorrect / unanswered。

填空题：

- 第一版使用保守核对：
  - 完全匹配或简单标准化后匹配，标记 correct。
  - 明显不匹配，标记 incorrect。
  - 不能确认，标记 needs_review。

解答题：

- 默认结果为 needs_grading。
- 显示标准答案与解析。
- 提供“问 AI 评分”入口。
- AI 评分结果标记为 reference，不作为绝对分数。

### 4.5 练习后动作

结果页动作：

- 查看解析。
- 加入错题。
- 标记掌握。
- 加入复习规划。
- 问 AI 评分。
- 查看历史记录。
- 再次练习，占位。

“再次练习”第一版行为：

- 显示为可见按钮。
- 点击后提示“再次练习将在后续版本开放”或保留禁用占位。
- 不创建新的 attempt。

## 5. 数据模型

### 5.1 practice_set

已有对象，表示练习单本身。

字段方向：

- `set_id`
- `user_id`
- `title`
- `subject`
- `exam_type`
- `library_name`
- `source_question_id`
- `question_ids`
- `matching_topics`
- `criteria`
- `created_at`
- `status`

职责：

- 保存练习单题目集合。
- 不保存用户本次作答。

### 5.2 practice_attempt

新增用户层对象，表示一次练习记录。

建议字段：

```json
{
  "attempt_id": "att_xxx",
  "user_id": "tester",
  "practice_set_id": "set_xxx",
  "status": "draft | submitted | abandoned",
  "started_at": "2026-07-04T20:00:00+08:00",
  "submitted_at": "2026-07-04T20:30:00+08:00",
  "duration_seconds": 1800,
  "answers": {
    "question_id": {
      "answer_type": "choice | blank | solution",
      "value": "B",
      "updated_at": "2026-07-04T20:05:00+08:00"
    }
  },
  "results": {
    "question_id": {
      "status": "correct | incorrect | unanswered | needs_review | needs_grading",
      "standard_answer": "B",
      "auto_checked": true,
      "ai_score": null,
      "ai_feedback": ""
    }
  },
  "summary": {
    "total": 5,
    "correct": 2,
    "incorrect": 1,
    "unanswered": 1,
    "needs_review": 1,
    "needs_grading": 1
  }
}
```

存储位置建议：

```text
data/user_message/{user_id}/system_library/practice_attempts.jsonl
```

如果当前用户层数据仍在其他目录，第一版应沿用现有系统资料库用户数据位置，不做大迁移。

### 5.3 review_signal

`review_signal` 不需要第一版单独落库，可以由 attempts 汇总生成。

后续 AI 规划可使用：

- 知识点正确率。
- 连续错误题。
- 错题次数。
- 练习次数。
- 最近一次提交时间。
- 多次练习趋势。

## 6. 与复习规划的关系

复习规划页未来需要能看到练习单任务的状态：

- 未开始练习。
- 草稿中。
- 已提交。
- 有错题待复习。
- 有解答题待评分。

练习结果可以产生建议：

- 把错题加入复习规划。
- 把低正确率知识点加入复习规划。
- 对已掌握且连续正确的知识点降低复习优先级。

第一版只需要保存足够数据，不要求立即完成 AI 规划页。

## 7. 页面与按钮闭环

| 功能 | 设置入口 | 数据变化 | 完成态显示 | 反向操作 |
| --- | --- | --- | --- | --- |
| 开始练习 | 练习单详情、复习规划任务 | 创建 draft attempt | 练习页显示草稿中 | 暂存退出、放弃本次 |
| 作答 | 题目下方输入控件 | 更新 attempt.answers | 右侧答题卡变为已答 | 清空单题答案 |
| 提交练习 | 右侧答题卡 | attempt.status=submitted | 进入结果页 | 不可修改 |
| 核对选择题 | 提交后自动 | 写入 question_result | 显示正确/错误 | 无，标准答案来自系统层 |
| 核对填空题 | 提交后自动保守核对 | 写入 correct/incorrect/needs_review | 显示待核对 | 用户查看解析后手动处理 |
| 解答题评分 | 结果页“问 AI 评分” | 写入 ai_score/ai_feedback | 显示 AI 参考评分 | 可重新请求评分，但保留历史 |
| 加入错题 | 结果页单题动作 | 更新用户题目状态 | 题目标记错题 | 移出错题 |
| 加入复习规划 | 结果页动作 | 创建 review_task | 复习规划页显示任务 | 取消、推迟、删除 |
| 再次练习 | 结果页按钮 | 第一版不变 | 占位提示 | 无 |

## 8. 错误与空状态

需要覆盖：

- 练习单不存在。
- 练习单题目加载失败。
- 草稿保存失败。
- 提交时网络失败。
- 标准答案缺失。
- 填空题无法自动核对。
- AI 评分失败。

建议体验：

- 草稿保存失败时显示明确提示，不阻止用户继续编辑。
- 提交失败时保留草稿。
- 标准答案缺失时该题标记 needs_review。
- AI 评分失败时允许重新发起。

## 9. 验收标准

第一版完成后应满足：

- 从练习单详情页可以进入练习页。
- 选择题、填空题、解答题都能填写答案。
- 右侧答题卡能反映作答进度。
- 提交前有不可修改提示。
- 提交后生成不可修改的 attempt。
- 选择题能自动判对错。
- 填空题能保守核对或标记待核对。
- 解答题能显示标准答案与解析，并提供 AI 评分入口。
- 结果页能把错题加入错题本或复习规划。
- 再次练习只作为占位存在。
- 不改系统题库公共内容，只写用户层数据。

## 10. 后续扩展

后续可以逐步做：

- 再次练习生成新 attempt。
- attempt 历史趋势图。
- 练习结果汇总到知识点掌握分析。
- AI 复习规划建议。
- 手写过程上传与 OCR/VLM 辅助理解。
- 更强的数学表达式等价判断。
