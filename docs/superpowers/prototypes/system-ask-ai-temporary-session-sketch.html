解题入口

这道题的核心不是直接积分，而是先从 f(x) 的图像判断正负区间，再推出 F(x)=∫0^x f(t)dt 的单调性。

第一步，看 x 从 0 向右移动时，f(t) 的符号如何变化；第二步，寻找 F'(x)=f(x) 的零点；第三步，用面积变化判断函数图像的上升、下降与极值。

易错点：不要把原函数 f(x) 的极值点直接当成 F(x) 的极值点，F(x) 的极值由 f(x)=0 且符号变化决定。
