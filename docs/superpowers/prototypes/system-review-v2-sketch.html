重复规划规则

同一道题同一天已存在任务时，不直接重复创建；允许同一道题在不同日期复习。

推荐：修改已有任务日期

如果还是这道题，只是想改复习时间，就更新原任务，避免规划页堆重复。

添加另一个日期

同一道题可在 7月4日、7月11日、7月25日多次复习，但每个日期只保留一个任务。

按知识点生成计划

如果目标是复习“极限”这个知识点，就创建 knowledge_point 类型任务，而不是重复塞同一道题。
