# 2001 数学二第 10
## 题目

For the differentiable function $y=f(x)$ shown below, choose the graph of $y=f'(x)$.

A. Graph A  B. Graph B  C. Graph C  D. Graph D

![diagram](../images/q010_diagram.png)

## 标准答案

D

## 解析

Read the sign changes of $f'(x)$ from the monotonicity of the given graph. Only option D matches.
