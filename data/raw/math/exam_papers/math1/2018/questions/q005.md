# 2018 数学一第 5 题

## 题目

下列矩阵中，与矩阵

$$
[1 1 0
 0 1 1
 0 0 1]
$$

相似的为（ ）

选项：

A.
$$
[1 1 -1
 0 1  1
 0 0  1]
$$

B.
$$
[1 0 -1
 0 1  1
 0 0  1]
$$

C.
$$
[1 1 -1
 0 1  0
 0 0  1]
$$

D.
$$
[1 0 -1
 0 1  0
 0 0  1]
$$

## 标准答案

A

## 解析

记原矩阵为
$$
J=\begin{pmatrix}
1&1&0\\
0&1&1\\
0&0&1
\end{pmatrix}.
$$
矩阵 $J$ 只有特征值 $1$，且
$$
r(J-E)=2,
\qquad
(J-E)^2\ne O,
\qquad
(J-E)^3=O.
$$
因此 $J$ 对应特征值 $1$ 的 Jordan 块大小为 $3$。

逐项考察 $M-E$ 的秩与幂零阶。A 选项满足
$$
r(M-E)=2,
\qquad
(M-E)^2\ne O,
\qquad
(M-E)^3=O,
$$
与 $J$ 有相同的 Jordan 结构；而 B、C、D 选项均有 $r(M-E)=1$，Jordan 结构不同。

所以与原矩阵相似的是 A。
