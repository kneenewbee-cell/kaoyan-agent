# 2019 数学一第 2 题

## 题目

设函数

$$
f(x) = {
  x|x|,  x <= 0,
  x ln x, x > 0
}
$$

则 `x=0` 是 `f(x)` 的（ ）

选项：

A. 可导点，极值点。
B. 不可导点，极值点。
C. 可导点，非极值点。
D. 不可导点，非极值点。

## 标准答案

B

## 解析

先看 $x=0$ 处的右导数：

$$
f'_+(0)=\lim_{x\to 0^+}\frac{f(x)-f(0)}{x}=\lim_{x\to 0^+}\ln x
$$

该极限不存在，所以 $x=0$ 是不可导点。又因为 $f(0)=0$，且在 $x=0$ 的左右邻域内都有 $f(x)<0$，所以 $x=0$ 是极大值点，故选 B。
