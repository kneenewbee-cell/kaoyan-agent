# 2019 数学一第 1 题

## 题目

当 `x->0` 时，若 `x-tan x` 与 `x^k` 是同阶无穷小，则 `k=（ ）`

选项：A. `1`  B. `2`  C. `3`  D. `4`

## 标准答案

C

## 解析

由麦克劳林展开式

$$
\tan x = x + \frac{x^3}{3} + o(x^3)
$$

可得

$$
x - \tan x = -\frac{x^3}{3} + o(x^3),
$$

因此 $x-\tan x$ 与 $x^3$ 是同阶无穷小，故 $k=3$，选 C。
